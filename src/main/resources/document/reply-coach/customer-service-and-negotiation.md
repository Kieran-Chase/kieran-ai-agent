# Reply Coach - Customer Service and Negotiation

## Core principle

Rights-protection communication should be clear, evidence-based, and deadline-oriented. Avoid insults and empty threats.

## Complaint structure

Order or issue + facts + evidence + request + deadline.

## Refund template

"Hello, the product/service I purchased does not match the description. The main issues are: ... My request is a refund. Please help process it or provide a clear solution within 24 hours."

## Escalation template

"I cannot accept the current result because .... Please escalate this case to a supervisor or specialist and provide a clear processing deadline."

## Negotiation structure

Recognition + condition + bottom line.
Example: "I understand this price, but it is above my budget. If it can be adjusted to X, I can confirm today; otherwise I need to compare other options."

## Chinese response guidance

For Chinese users, provide polite but firm Chinese wording. Include formal written version and short chat version.

## Common situations

- Refund request
- Complaint escalation
- Compensation negotiation
- Price negotiation
- Service cancellation
- Delivery or quality dispute
